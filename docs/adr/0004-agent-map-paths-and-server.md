# ADR-0004 — 에이전트 지도: 파일 경로 저장과 로컬 서버 (사용자 결정)

- 상태: 승인 (2026-11-03, 사용자 직접 결정)
- 관련: https://github.com/reddol18/moni_token/issues/3 , CLAUDE.md 절대 규칙 1, ADR-0001

## 맥락

이슈 #3의 에이전트 지도는 서브에이전트가 지금 프로젝트의 어디(소스 트리·UI 페이지·기능)에서 일하는지 보여 준다.
위치는 도구 입력(Read/Edit/Write/Grep/Glob의 파일 경로)에서만 얻을 수 있다.
절대 규칙 1은 숫자와 메타데이터만 저장하도록 정했고, 파일 경로는 그 목록에 없었다.

또 지금 리포트는 2분마다 다시 쓰는 정적 HTML이라 "지금"을 보여 주기에 느리다.

## 결정

1. **프로젝트 기준 상대 경로를 DB에 저장한다.**
   - 저장: 도구 이름, 프로젝트 루트 기준 상대 경로(예: `src/auth/login.ts`), 시각, 세션·에이전트 id.
   - 저장하지 않음: 파일 내용, 편집 내용(old/new 문자열), 명령 문자열, 검색 패턴, URL 이외의 도구 입력 전부.
   - 프로젝트 루트 밖 경로(홈 디렉토리, 다른 프로젝트)는 저장하지 않는다. 경로를 루트 기준으로 바꿀 수 없으면 버린다.
   - 이유: 지난 사건을 돌아볼 때 "에이전트들이 어느 폴더를 헤맸나"를 볼 수 있어야 원인 분석에 쓸 수 있다(사용자 선택).
2. **실시간 화면은 127.0.0.1 전용 로컬 서버로 띄운다.**
   - 외부 인터페이스에 바인드하지 않는다. CDN·외부 요청 없음(기존 리포트와 같은 원칙).
   - 기존 정적 리포트는 그대로 둔다.
3. 기능 보기는 계약 md에 **명시된 경로·이름**으로만 파일을 기능에 연결한다. LLM·추측 없음.

## 대안

- 경로를 메모리에만 두기: 디스크에 남지 않지만 과거 사건을 돌아볼 수 없다. 기각.
- 정적 HTML 갱신 주기를 줄이기: 파일 쓰기가 잦아지고 여전히 몇 초~분 늦다. 기각.

## 결과

- 절대 규칙 1에 "프로젝트 기준 상대 파일 경로"가 저장 허용 메타데이터로 추가된다(CLAUDE.md 갱신).
- DB 스키마 버전이 오른다. 상대 경로는 로그에서 다시 만들 수 있으므로 재생성으로 처리한다.
- 테스트로 강제: 파일 내용·편집 문자열·명령 문자열·루트 밖 경로가 DB에 들어가지 않음(기존 SECRET 검사 확장).

## 추가 결정 (2026-11-05, 사용자 지시 "남은 작업 진행")

- 서브에이전트의 **작업 설명**(`agent-*.meta.json`의 `description`, 부모가 붙인 짧은 제목)을 지도 화면에 **보여 주기만** 한다.
  - 요청할 때마다 메타 파일에서 읽고 80자로 자른다. DB·로그·정적 리포트에는 넣지 않는다(테스트로 강제).
  - 이유: "어떤 일을 하고 있는지"가 가장 잘 드러나는 정보다. 화면은 127.0.0.1에서만 열린다.
