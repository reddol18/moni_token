- 모든 CLI는 시각을 로컬 시간으로 표시한다. 새 명령: `status`, `blocks`, `spikes [--all]`, `check`, `suggest-floor`.

## 가격표 근거
- `claude-api` 스킬 로드는 자동 모드 분류기에 막혔다. 우회하지 않았다.
- 대신 로컬 로그의 `cost-state`(Claude Code가 직접 계산한 모델별 비용)로 단가를 역산했다. 외부 접속은 없다.
  - Haiku 4.5: $1/$5, 웹 검색 $10/1k → 정확히 재현됨(`verified = true`)
  - Sonnet 5: $2/$10, 5분 캐시 쓰기 1.25× → 정확히 재현됨
  - Opus 계열: 입력 약 $5(4.7은 오차 0.1%). 출력은 표본이 부족해 입력의 5배로 가정 → $5/$25 (`verified = false`)
  - Opus 5.5는 맞춤이 불안정하다(n=15). 같은 값을 두고 미검증으로 표시했다. Fable 5.1은 표본이 없어 $10/$50으로 가정했다.
- 단위$는 원인끼리 비교하는 상대 척도라서, 계열 안의 비율(캐시 읽기 0.1×, 1h 쓰기 2×)이 맞으면 판정에는 영향이 없다. 공식 가격 확인은 사용자 승인 사항으로 남긴다.
