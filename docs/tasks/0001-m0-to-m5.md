## 최우선 원칙 (다시 강조)
- **실행 중 LLM 0회** — 판정·원인 분석·설명문 모두 결정론적 코드. 테스트로 강제.
- **개발 중에도 토큰 절약** — 원본 JSONL을 대화로 읽지 말고 스크립트로 집계해 숫자만 본다. headless `claude -p` 실험은 원칙적으로 금지(필요하면 지휘부 승인).
- 대화 원문 미저장, 로그 읽기 전용, 외부 전송 없음.

## 사용자 위임 사항
- Python 의존성 설치(`uv`), 로컬 `git init`과 마일스톤 단위 로컬 커밋. GitHub 원격·푸시 금지.
- 상주 수집기 자동 시작 등록(작업 스케줄러 등)은 **M5에서 방식 확정 후 사용자 확인**을 받고 한다.
